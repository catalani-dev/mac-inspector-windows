## IEEE Registration Authority data

`oui-data.json` is generated by `build-oui-database.py`, published with the [MAC Inspector Chrome extension](https://github.com/catalani-dev/mac-inspector), from the public listings of the IEEE Registration Authority:

| Registry | File |
|---|---|
| MA-L | `oui.csv` |
| MA-M | `mam.csv` |
| MA-S | `oui36.csv` |
| IAB | `iab.csv` |
| CID | `cid.csv` |

Source: <https://standards-oui.ieee.org/>
